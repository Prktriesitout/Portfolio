1. EXECUTIVE SUMMARY & WHAT HAS BEEN BUILT
--------------------------------------------------------------------------------
This project consists of two core components:

A. Windows XP Luna-Style Personal Portfolio (Static Frontend)
   - Built with pure HTML5, CSS3, and vanilla JavaScript (no npm, no bundlers,
     no frameworks, zero external dependencies/CDNs).
   - Engineered specifically for GitHub Pages static hosting under a sub-path or custom domain.
   - Authentic Windows XP Luna desktop UI with full window management, taskbar,
     start menu, file explorer, viewers, and a certifications showcase.

B. Portfolio AI Assistant API (FastAPI Backend in `server/`)
   - Lightweight, production-grade, hardened FastAPI service designed to power an
     interactive portfolio AI assistant.
   - Strict security layer: rate limiting, conversation limits, input sanitization,
     request body size guards, security headers, IP hashing, and prompt injection defense.
   - Comprehensive test suite in `server/tests/` (40 passing tests).

4. HOW TO RUN & TEST LOCALLY
--------------------------------------------------------------------------------

A. Running Frontend Locally:
   Option 1: Python HTTP Server
     python -m http.server 8000
     Open browser: http://localhost:8000/
   (Note: Use a local server; file:// URLs will block fetch() calls)

B. Running Backend API Locally:
   cd server
   ..\.venv\Scripts\uvicorn app.main:app --reload --port 8080
   Health check: http://localhost:8080/api/health

C. Running Backend Test Suite:
   ..\.venv\Scripts\pytest server\tests
   (Currently: 40 passed in ~2 seconds)
